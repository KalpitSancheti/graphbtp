📝 HOW TO USE
═══════════════════════════════════════════════════════════════

1. Enter Graph 1:
   ├─ Number of vertices (e.g., 4)
   └─ Edges, one per line (e.g., 0 1)

2. Enter Graph 2:
   ├─ Number of vertices (e.g., 4)
   └─ Edges, one per line (e.g., 0 1)

3. Click "Check Isomorphism"

4. View results!


💡 EXAMPLE INPUT
═══════════════════════════════════════════════════════════════

Square Graph:
   Vertices: 4
   Edges:
   0 1
   1 2
   2 3
   3 0

Triangle Graph:
   Vertices: 3
   Edges:
   0 1
   1 2
   2 0
